# EncodeNavi

YMM4でタイムラインの素材を調べて目的に合った動画出力の設定を提案するツールプラグインです。

推奨値にはそれぞれ理由が付きます。YMM4の動画出力画面を開くと推奨と違う欄に直接印が付くので、どこを何に変えればいいかがその場で分かります。

## 概要

| 機能 | 内容 |
|---|---|
| 素材の解析 | タイムライン上の動画・音声アイテム（シーンの中も含む）を調べます。動画は解像度・fps・ビットレート・コーデック・ビット深度、音声はサンプリングレート・チャンネル数・ビットレートに加えて、実際に入っている音の高さの上限や、左右が同じ音（実質モノラル）かどうかも見ます |
| 目的別の推奨 | 「容量優先」「投稿先に最適化（YouTube / ニコニコ動画 / X）」「速度優先」から選びます。解像度・fps・サンプリングレート・映像の画質・preset・音声のビットレートとチャンネル・ハードウェアエンコードの使い方を提案します |
| 2つの出力方法に対応 | 「FFmpeg出力」と「MediaFoundation出力」のどちらを使っていても、それに合わせた推奨を出します |
| 動画出力画面への表示 | 動画出力画面を開くと、推奨と違う欄に推奨値を重ねて表示します。表示は「デフォルト」「カラー」「サイバー」から選べます |
| 詳細ウィンドウ | 動画出力画面の「詳細」から、推奨値の理由やコピー用のコマンドを別ウィンドウで確認できます。動画出力画面を開いたままでも操作できます |
| 音量の確認 | ボイス・BGM・効果音をまとめた動画全体の音量（LUFS）とピークを測り、音量調整と音割れ対策の設定を提案します |
| 出力中の映像表示 | 出力中のウィンドウに、いま出力しているあたりの映像を約1秒ごとに表示します |

## 使い方

1. YMM4 の「ツール」から **EncodeNavi** を開きます。
2. 「出力方法」と「目的」を選びます。「投稿先に最適化」では投稿先も選びます。
3. 素材が自動で解析され、推奨設定が理由付きで表示されます。推奨と違う項目は強調表示されます。
4. YMM4 の動画出力画面を開くと、推奨と違う欄に推奨値が表示されます。設定を直すと、その表示は消えます。
5. 動画出力画面の一番上の「EncodeNavi 目的」（「投稿先に最適化」では「投稿先」も）から、目的を切り替えられます。

### FFmpeg出力のとき

推奨の映像コマンド・音声コマンドを、動画出力画面の「映像コマンド」「音声コマンド」欄に貼り付けます。どちらも画面の「コピー」ボタンでコピーできます。

> [!Note]
> コマンドで画質（crf）や preset を指定するときは、「映像ビットレート」を **指定しない**、「ハードウェアエンコード」を **オフ** にしてください。そのままだと YMM4 がコマンドの指定を上書き・削除します。動画出力画面の「プレビュー」は削除される前の内容なので、プレビューに出ていても実際の出力では消えていることがあります。

推奨の解像度・fps・サンプリングレートがプロジェクトと違う場合は、その変換もコマンドに含まれます。プロジェクト設定を変える必要はありません。

### MediaFoundation出力のとき

コマンド欄がないため、動画出力画面の「エンコード設定」「詳細設定」の各欄を推奨値に合わせてください。MediaFoundation出力はH.264固定・音声はステレオ固定で、出力時に解像度や fps を変換できません。変える必要がある場合はプロジェクト設定で変更してください。

## 設定

パネルと詳細ウィンドウのどちらからでも変えられます。

| 設定 | 初期値 | 内容 |
|---|---|---|
| 自動で解析する | オン | パネルや動画出力画面を開いたときに自動で解析します。変更されていない素材は前回の結果を使うので、2回目以降はすぐに終わります。オフにすると「解析」ボタンで解析します |
| 音量も確認する | オン | 動画全体の音量を測って、音量調整と音割れ対策の設定も提案します。動画の長さに応じて解析に時間がかかります |
| 出力中に映像を表示する | オン | 出力中のウィンドウに映像を表示します |
| 出力画面の表示 | デフォルト | 動画出力画面に重ねる表示の見た目です。お遊びでいくつかテーマが追加されてます。 |

## 注意

- YMM4の設定は書き換えません。推奨を表示するだけで、設定を変えるのは利用者です。
- 投稿先の数値のうち、YouTubeとXは公式の情報をもとにしています。ニコニコ動画は、音量の基準（-15 LUFS）と、投稿した解像度・音声ビットレートで決まる配信画質・音質の条件が公式の情報です。映像ビットレートは公式の推奨値がないため目安です。
- 素材の解析の対象は動画アイテムと音声アイテムです。ボイスアイテムと画像アイテムは対象外です（「音量も確認する」では、ボイスも含めた動画全体の音を測ります）。
- 出力中の映像表示は、表示用に同じフレームを別に描画しています。出力そのものには影響しませんが、出力がわずかに遅くなることがあります。
